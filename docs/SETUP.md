# Setup Guide

## Prerequisites
- Node.js 22+
- pnpm 9+

## Installation
```bash
pnpm install
```

## Build
```bash
pnpm build
```

## Environment Variables
Copy .env.example to .env and fill in:
- SOLANA_RPC_URL
- BITCOIN_RPC_URL
- JWT_SECRET
- DATABASE_URL

## API Keys
Contact admin for API keys needed for development.
